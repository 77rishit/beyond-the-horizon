# Beyond The Horizon

Build the initial version of a premium interactive parallax scrolling website called "BEYOND THE HORIZON".

Create a full-screen cinematic landing page with:

- Dark futuristic aesthetic

- Minimal transparent navbar

- Logo/text: BEYOND

- Navigation: Journey, Worlds, Explore

- Full-screen hero section

- Large headline: "BEYOND THE HORIZON"

- Subtitle: "Scroll to enter a world in motion."

- CTA button: "BEGIN THE JOURNEY"

- Animated "SCROLL TO EXPLORE ↓" indicator

- Beautiful layered landscape background

- Mountains, clouds, sun/moon and foreground elements

Use React + Tailwind CSS.

Set up the page architecture so additional parallax sections can easily be added later.

Make it responsive for desktop, tablet and mobile.

Do NOT make it look like a generic landing page. Make it cinematic, premium and visually impressive.
